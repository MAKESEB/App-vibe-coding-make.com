# Abstract Make Custom App

This generated app provides a minimal, local Make custom app for Abstract.

## API documentation

- Docs: https://docs.abstractapi.com/email-validation
- Base URL: `https://emailvalidation.abstractapi.com`
- Authentication: api_key query parameter

## Included module

- **Make an API Call** (`makeAnApiCall`) sends a custom request relative to the documented base URL and applies the app-specific authentication behavior.

## Notes

Do not add api_key in Query String. The module injects it from the connection.
